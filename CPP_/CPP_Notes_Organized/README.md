## 📚 Topics Covered

- Functions and function overloading
- Classes, objects, and basic OOP programs
- Function overriding and runtime polymorphism
- Single, multilevel, multiple, and hierarchical inheritance
- Function, class, and inherited templates
- STL containers: `vector`, `list`, `map`, and `stack`
- Stream manipulators such as `setw`, `setprecision`, `fixed`, and `boolalpha`
- Basic file reading with streams

## ▶️ How to Run a Program

Compile any `.cpp` file separately with a C++ compiler such as `g++`: 

```bash
g++ 06_STL/Vector.cpp -o vector
./vector
```

On Windows, run the generated executable using `vector.exe`. Each program is an independent example; compile one file at a time.
